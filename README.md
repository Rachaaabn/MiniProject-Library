## Features Implemented (100 % conforme au sujet)
- Coordinator Server: broadcasts searches, aggregates results, forwards lease/return, ignores unresponsive servers  
- Three independent Library Servers with local statistics  
- Client with all required commands: search, lease, return, stats, list, quit  
- Book leasing and returning system  
- Search statistics (most searched keywords and books)  
- Pure TCP sockets (no external libraries, no database)  
- Fault tolerance (unresponsive libraries are ignored)
